# Fethiye İK

An early professional web project for a recruitment and personnel-services business in Fethiye.

**Status:** Historical delivery; the website remains live.  
**Live site:** [fethiyeik.com](https://fethiyeik.com/)

## Project Scope

The site is a responsive, multi-page web property covering company information, service categories, service areas, reference content, contact information, and editorial pages.

The implementation includes:

- semantic HTML pages for core business and service content
- shared CSS component and responsive layout layers
- JavaScript interactions and animation behavior
- dedicated service-area and blog routes
- search-engine-facing sitemap and robots files

## Technology

HTML, CSS, and JavaScript.

This repository is kept public to show progression and real-world delivery. It is not positioned as a current flagship system.
